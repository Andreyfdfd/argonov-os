# ⚡ Argonov OS

Кастомная оболочка для Termux на Android.

## Возможности

- 🤖 AI-ассистент (Qwen 2.5 Coder 3B локально)
- 📈 Crypto Informer (курсы в реальном времени)
- 🎵 Music Player (библиотека, жанры, типы)
- 📌 Todo (трекер с уведомлениями)
- 📝 Notes (заметки с тегами)
- 🔒 PassManager (AES-256)
- 🎮 HackTool (легальный OSINT)
- 📥 Download Zone (aria2c)
- 🌧 Matrix, 🔐 Passgen, ⚡ Sysinfo

## Установка

git clone https://github.com/Andreyfdfd/argonov-os.git
cd argonov-os
bash install.sh

## Использование

argonov              # меню
argonov help         # справка
argonov ai           # AI-ассистент
argonov doctor       # проверка сетапа
